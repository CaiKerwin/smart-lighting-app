# Light 智慧路灯 App 使用的后端接口文档


## 3. 通用请求/响应约定

### 3.1 请求头（`HttpHelper.getRequestBuilder`）

| Header    | 值                 | 说明      |
|-----------|-------------------|---------|
| `auth`    | 登录 token          | 登录前为空   |
| `Custid`  | 客户 ID             |         |
| `Apptype` | 应用类型（curApp）      |         |
| `Lang`    | `zh_cn` / `en_us` | 由本地语言映射 |

### 3.2 请求体封装

- POST / PUT 的 JSON 统一包装为：`{"content": Base64(业务JSON)}`（`HttpHelper.getBody`）。
- 上传图片等使用 `multipart/form-data`（`getPostPicRequest`）。
- `getLoginBody`（明文 content）已定义但当前**未使用**，登录接口同样走 Base64 包装。

### 3.3 响应封装（`BaseViewModel.requestData`）

```json
{
  "code": 0,          // 业务状态码，0 表示成功
  "data": "...",      // 业务数据；若 "abab" != "false"，则 data 为 Base64(AES) 密文，需解密
  "abab": "false"     // 加密标识
}
```

- HTTP 200 且业务 `code == 0` 才算成功；`data` 为 `null` / `"[]"` / `"{}"` 时按“暂无数据”处理。
- 业务失败时统一回调 `errorLiveData`（`ErrorBean(errorCode, errorMessage, errorUrl)`），页面根据 `errorUrl` 区分具体接口。

### 3.4 业务错误码

| 码      | 含义                             |
|--------|--------------------------------|
| 0      | 成功                             |
| 200    | HTTP 成功（`NetworkCode.SUCCESS`） |
| 400    | HTTP 参数错误                      |
| 408    | 请求失败/超时                        |
| 990008 | 登录过期，需重新登录                     |
| 990011 | 账号校验类错误                        |
| 990012 | 设备已存在                          |

## 6. 指令发送协议（SendPowerboxOld / SendLampOld / SendOutputOld / SendCommand）

指令类接口请求体为命令 JSON，统一结构：

```json
{
  "code": "命令码",
  "list": [设备ID...],
  "checkUserId": 用户ID,
  "args": { }
}
```

常用命令码（`OrderUtil`）：

| 命令码                               | 含义          | 适用        |
|-----------------------------------|-------------|-----------|
| `forceRead`                       | 远程召测        | 配电箱/单灯/水浸 |
| `getclock`                        | 读取时钟        | 配电箱/单灯    |
| `setclock`                        | 校准时钟        | 配电箱/单灯    |
| `resetDevice`                     | 重启设备        | 配电箱       |
| `handSingle`                      | 单灯开关/调光/色温  | 单灯        |
| `handAll`                         | 群控单灯        | 单灯        |
| `handControl`                     | 通道开关        | 输出通道      |
| `handGroup1`                      | 工厂组控调光      | 配电箱（工厂）   |
| `setDayPlan1` / `setDayPlan2`     | 设置计时/准时日表   | 单灯        |
| `setPlanType`                     | 设置控制模式      | 单灯        |
| `setLatLng` / `getLatLng`         | 设置/读取坐标     | 设备        |
| `setAlarmRange` / `getAlarmRange` | 设置/读取水浸报警区间 | 水浸        |
| `setClockArgs` / `getClockArgs`   | 设置/读取水浸采集参数 | 水浸        |
| `getInfo`                         | 读取设备信息      | 水浸        |

`args` 示例：

```json
// handSingle
{"bright1":100,"bright2":100,"bright3":100,"bright4":100,
 "color1":0,"color2":0,"color3":0,"color4":0,"expire":"2026-08-31 18:00:00"}

// handControl
{"open":true,"enable":true,"point":false,"expire":"2026-08-31 18:00:00"}

// setPlanType
{"ch":1,"type":0}
```

响应模型：`NewCommandResultBean`（`data.list[]`：`{id, success, message}`）；最终执行结果通过 WebSocket 推送（见 §8）。

指令记录统一请求体（`CommandViewModel.commandHistory`）：

```json
{"groupId":0,"stationId":0,"code":"设备ID","name":"","start":"起始时间","end":"结束时间","index":1,"size":30}
```

响应模型：`CommandHistoryBean`（`data.list[]`：`stationName/code/paramName/commandName/sendUserName/sendTime/statusName`）。

## 8. WebSocket 实时通道

### 8.1 连接

- 地址：`{root}api/center/data`（生产 `wss://www.amdm.top/api/center/data` 或 `wss://yonghengguang.amdm.top/api/center/data`）。
- 断线自动指数退避重连（1s→30s 封顶）；连接成功后发送心跳。

### 8.2 心跳（客户端 → 服务端）

```json
{
  "cmd": "heart",
  "data": {
    "time": 1725000000000,
    "appType": "应用类型",
    "customerId": "客户ID",
    "token": "登录token"
  }
}
```

前 10 次心跳间隔 2s，之后每 20s 一次。

### 8.3 服务端推送（命令执行结果 / 状态）

消息为 JSON 字符串，关键字段（由各页面 `handleSocket` 解析）：

| 字段                       | 说明                                                     |
|--------------------------|--------------------------------------------------------|
| `type`                   | 消息类型（`cmd` 为指令结果）                                      |
| `cmdCode`                | 命令码（如 `handControl`、`forceRead`、`getclock`、`setclock`） |
| `commandId`              | 命令 ID（客户端发送时生成的 UUID，用于匹配自己发起的指令）                      |
| `status`                 | 执行状态：2 已发送 / 4 执行中 / 5 已重发 / 7 超时 / 8 失败 / 9 成功        |
| `content`                | 结果内容（如 `getclock` 返回 `{"nowTime":"..."}`）              |
| `cmd` / `state` / `data` | 其他状态推送字段                                               |

消费方：`PowerBoxActivity`、`FactoryBoxActivity`、`SingleDetailActivity`、`SingleTestActivity`、`NewGroupControlActivity`、`NewWaterBoxActivity`、`WaterBoxActivity`、`CommandListDialogFrag`、`WaterCommandListDialog`、`FastGroupChannelFragment`、`FastGroupLightFragment`。
